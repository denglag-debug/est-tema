# Есть тема. Зови своих.

Сайт проекта «Есть тема»: готовые сценарии домашних встреч. Первый сет: «Баскская вечеринка».

Сайт публикуется через GitHub Pages из ветки `main`.

- `index.html` - главная страница
- `basque/` - онлайн-версия баскского сета и PDF
- `img/` - рисунки и карта

Исходники лежат в папке `site/` проекта; эта папка собирается скриптом `sobrat-dlya-github.py`.
